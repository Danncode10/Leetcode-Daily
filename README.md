# Leetcode-Daily

---

This GitHub repository is a personal coding journal where you're solving at least one LeetCode problem every day. You're organizing your solutions by difficulty (Easy, Medium, Hard), and optionally including notes, problem links, and contest performance.

The goal is to:
- Practice daily to build consistency
- Improve at data structures and algorithms
- Prepare for coding interviews and competitive programming
- Track your growth and progress over time
